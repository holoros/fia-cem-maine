# PERSEUS CONUS forest yield curves (FIA hybrid + recalibrated growth projections)

This dataset provides 100-year projected forest stock trajectories for the 48 conterminous
United States, derived from USDA Forest Inventory and Analysis (FIA) plot data using the
PERSEUS hybrid yield-curve engine. Five stock metrics are projected under twelve management
and disturbance scenarios, at the state level, in 10-year steps from 2025 to 2125.

It is the data layer behind the PERSEUS Forest Intelligence dashboard
(https://holoros.github.io/perseus-forest-intelligence).

## Files

- `fia_hybrid_fullseries_agc.csv` - above-ground live tree carbon (Tg C)
- `fia_hybrid_fullseries_agb.csv` - above-ground dry biomass (Tg)
- `fia_hybrid_fullseries_vol_stem.csv` - live stem volume (Mm3)
- `fia_hybrid_fullseries_merch_vol_mcf.csv` - merchantable volume (Mcf)
- `fia_hybrid_fullseries_merch_bio_dry.csv` - merchantable bole dry biomass (Tg)
- `fia_mgmt_shares_bystate.csv` - FIADB per-state reserved / planted / harvested shares
- `data_dictionary.csv` - column descriptions and units
- `METHODS.md` - model form, recalibration, scenarios, and provenance
- `CITATION.cff` - machine-readable citation

Each stock file is long format: `state, scenario, year, value, lo, hi`. The `lo` and `hi`
columns give the scenario band (for the disturbance and mortality variants) or equal the
central value (for the base buckets).

## Scenarios (the `scenario` column)

Four management regimes, each in three variants (base, disturbance-exposed,
mortality-stressed), for twelve buckets total:

- `reserve (no harvest)` - no harvest
- `managed (harvest)` - business-as-usual harvest on the observed working-forest fraction
- `managed (intensive)` - intensive management applied to the plantation fraction
- `managed (conservation)` - light/extended-rotation management on the working fraction

Managed scenarios apply the regime only to a FIADB-derived fraction of the land base
(harvested share for harvest/conservation, planted share for intensive); FIA reserved
(protected) plots are never harvested. See METHODS.md.

## Model form, in brief

Stocks are projected on a hybrid Chapman-Richards growth curve with a senescence decline
tail, recalibrated to the FIA longitudinal remeasurement increment and capped at the 95th
percentile of observed standing stock, fit per forest-type x EPA level-3 ecoregion x owner
cell. Disturbance-exposed variants apply an FIA-calibrated fire/insect disturbance drag;
mortality-stressed variants apply FIA growth-removal-mortality density mortality. State
totals are anchored to FIA design-based estimates at 2025.

## Coverage and units

48 CONUS states, 2025 to 2125 (10-year steps), state-level totals. Units per metric are in
`data_dictionary.csv`. A CONUS aggregate is the sum across states.

## Provenance and code

Generated by the PERSEUS yield-curve pipeline. Source code, decision records (ADR 0003 on
the engine form, ADR 0004 on the managed-scenario calibration), and methods notes are at
https://github.com/holoros/perseus-forest-intelligence (scripts/yield_curve_engine,
docs/decisions, docs/results).
